# Design Patterns Examples

This repository contains practical examples of commonly used **design patterns** implemented in Java. Each pattern is presented in a simple and clear way to help understand its **structure**, **purpose**, and **use case**.

## 🧠 Included Patterns

### Creational Patterns
- Singleton
- Factory Method
- Abstract Factory
- Builder
- Prototype

### Structural Patterns
- Adapter
- Bridge
- Composite
- Decorator
- Facade
- Flyweight
- Proxy

### Behavioral Patterns
- Observer
- Strategy
- Command
- Template Method
- Visitor
- State
- Mediator
- Chain of Responsibility

## 📁 Structure

Each pattern is organized in its own directory with:
- ✅ Example code
- 📄 Task list
